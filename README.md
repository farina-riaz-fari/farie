
# Farié

**Little Details, Made Special.**

Farié is a handmade accessories e-commerce platform focused on beautiful, personalized accessories and thoughtful gifts.

The platform will provide customers with an elegant shopping experience and an admin dashboard for managing products, inventory, orders, and customers.

## Project Overview

Farié is being developed as a web-first e-commerce platform, with plans to expand to a mobile application in the future.

### Planned Features

**Customer Website**
- Browse handmade accessories and collections.
- Explore product details and variations.
- Create personalized accessories.
- Wishlist and shopping cart.
- Checkout and order tracking.
- Customer accounts and order history.

**Admin Dashboard**
- Dashboard overview and analytics.
- Product and category management.
- Inventory management.
- Order management.
- Customer management.
- Custom order requests.

## Tech Stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- ESLint

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone git@github.com:farina-riaz-fari/farie.git
```

Navigate to the project directory:

```bash
cd farie
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start development server |
| `npm run build` | Create production build |
| `npm run start` | Start production server |
| `npm run lint` | Run ESLint |

## Git Workflow

The project uses a feature-based branching workflow.

| Branch | Purpose |
|---|---|
| `main` | Stable code |
| `develop` | Development integration |
| `feature/*` | Individual feature development |

Feature branches are merged into `develop` after completion and testing. Stable releases are merged into `main`.
